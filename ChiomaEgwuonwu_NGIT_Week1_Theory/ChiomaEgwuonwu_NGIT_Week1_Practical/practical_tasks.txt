Task 2: Command Line Practice
Commands used and their functions:
cd web_basics – Navigates into the web_basics folder
mkdir cli_practice – Creates a new folder
cd cli_practice – Moves into the cli_practice folder
touch test.txt – Creates a file (or type nul > test.txt on Windows)
mv test.txt myfile.txt – Renames the file
ls or dir – Displays files and folders in the directory
